# 💬 ChitChat — Real-Time MERN Chat Application

**ChitChat** is a real-time chat application built using the MERN stack (MongoDB Atlas, Express.js, React with Vite, Node.js), enhanced with JWT authentication, bcrypt for password security, and Socket.IO for live messaging.

---

## 🚀 Features

- 🔐 User Signup & Login (JWT-based Auth)
- 🔒 Secure Password Hashing with bcrypt
- 👥 See All Registered Users
- 💬 Real-Time One-to-One Messaging with Socket.IO
- 📂 Conversations Panel (Displays recent chats)
- ☁️ MongoDB Atlas Integration (Cloud-hosted DB)
- ⚡ Optimized Frontend with React + Vite

---

## 🛠️ Tech Stack

### Frontend
- React (Vite)
- Axios
- Socket.IO Client
- Tailwind CSS *(optional)*

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT (JSON Web Token)
- bcrypt.js
- Socket.IO
